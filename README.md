# kidswear-wholesale-website
Wholesale kidswear catalogue website with product collections and WhatsApp enquiries
Catalogue website for wholesale children's clothing.

## Features
- Kidswear product catalogue
- Limited-lot inventory
- Age-based filtering
- New arrivals
- Wholesale pricing
- WhatsApp enquiries
- Shipping information
- Mobile-first design

## Technology
- Astro
- HTML
- CSS
- JavaScript
- Cloudflare Pages
